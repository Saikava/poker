Manual Bundle Test

This page tests if the bundled poker UI application works correctly in the browser.

Test Instructions

  1. Build the application: npm run build
  2. Open dist/index.html in your browser
  3. Verify the following functionality:
    • Page loads without console errors
    • All UI sections are visible
    • Player management form is functional
    • Game controls are present
    • No JavaScript errors in browser console

Alternative: Development Server Test

  1. Start development server: npm run serve
  2. Open http://localhost:8080
  3. Test the same functionality as above
  4. Verify hot reloading works by making a small change to source files

Expected Results

  • ✅ Poker Engine UI loads successfully
  • ✅ All UI components are visible and styled
  • ✅ No console errors related to missing modules
  • ✅ Poker engine integration works (can add players)
  • ✅ Game state updates properly

Troubleshooting

If you encounter issues:

  • Check browser console for JavaScript errors
  • Verify all files exist in the dist/ directory
  • Run node test-bundle.js to verify build integrity
  • Try rebuilding with npm run clean && npm run build
